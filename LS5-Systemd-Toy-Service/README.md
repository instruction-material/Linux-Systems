# LS5 Systemd Toy Service

Run a small long-lived process under `systemd` and practice the daily commands
used to inspect and manage it.

## Outcomes

- read a service unit file
- start, stop, restart, enable, and inspect a service
- understand the role of working directory, environment, and restart policy
- diagnose failures with `systemctl status` and `journalctl`

## Deliverables

- a running service
- a service unit with correct paths
- a short failure-and-recovery note from an intentional break/fix exercise
