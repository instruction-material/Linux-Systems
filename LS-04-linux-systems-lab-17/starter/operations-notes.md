# Operations capstone runbook and evidence

This record is completed from the actual owned Linux run. A reference supplies
methods and source, not observations for another machine. Retain the original
source revision or downloaded archive hash and a versioned copy of this record.

1. Environment: kernel, PID 1, account/group, tool versions, filesystem/mount,
   available space, owned VM snapshot and the exact new lab id/root/ports.
2. Configuration: explain and record all four starter corrections. Predict the
   bind address, release identity, working-directory failure and backup members.
   Preserve the first failed checks and the corrected configuration/unit checks.
3. Ownership and identity: record operator UID, actual service PID/UID and
   invocation id, file/directory modes, code hash and actual denied write probe.
   Explain why the service cannot edit operator code or private backups.
4. Serving and diagnosis: retain actual direct/proxied health status and body,
   missing-route status, listener ownership, active manager state and scoped
   journal records. Identify what each observation proves and does not prove.
5. Scheduled backup: retain the actual timer trigger and backup-unit journal,
   manifest members/digests, archive checksum, source/destination devices and
   permissions. Keep manual backup execution distinct from scheduled execution.
6. Restore and failed output: restore into a separate new path, compare every
   byte/hash and ownership, then retain existing-destination refusal and a
   rejected partial candidate while proving the prior trusted archive unchanged.
7. Incident: predict and inject the missing working directory, retain failed
   service/journal/direct/proxy evidence, locate the first failure, restore the
   original unit, retest and demonstrate a separate clean stop/start.
8. Changed case and rollback: change one fictional input in an owned copy,
   predict which restart and new backup are needed, verify the changed case,
   then disable/remove only this run's units/config/tree. Record closed listeners,
   absent owned PIDs and any retained evidence or limitations.
