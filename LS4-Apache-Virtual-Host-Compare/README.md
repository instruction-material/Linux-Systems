# LS4 Apache Virtual Host Compare

Configure an Apache virtual host and compare its layout to the earlier Nginx
server block.

## Outcomes

- understand document roots and virtual hosts in Apache
- identify the Apache equivalents of Nginx server blocks
- enable a site, test config syntax, and reload safely
- compare how Apache and Nginx express similar hosting ideas

## Deliverables

- a working Apache virtual host
- a one-paragraph compare/contrast note
- a sample page served from the configured document root
