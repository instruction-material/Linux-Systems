# LS2 Static Site from /srv

Deploy a small static site from `/srv/linux-systems-site` and serve it with
Nginx.

## Outcomes

- understand why site content can live under `/srv`
- create a document root with safe ownership and permissions
- write a basic Nginx server block
- distinguish between `nginx -t`, reload, and restart

## Deliverables

- static content in `/srv/linux-systems-site`
- a server block enabled in Nginx
- a short note about why `/srv` is a better fit than `/tmp`
