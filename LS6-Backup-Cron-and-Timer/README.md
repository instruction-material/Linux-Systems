# LS6 Backup Cron and Timer

Write a simple backup script, then schedule it with both `cron` and a
`systemd` timer.

## Outcomes

- create a repeatable shell script for archiving a directory
- understand how environment differences can break cron jobs
- compare cron scheduling to `systemd` timers
- verify outputs, retention, and logs

## Deliverables

- a working backup script
- a cron entry and a timer pair
- a note explaining which scheduling model you would choose and why
