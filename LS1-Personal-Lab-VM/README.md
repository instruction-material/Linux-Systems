# LS1 Personal Lab VM

Provision a personal Linux practice environment and confirm it is safe for the
rest of the course.

## Outcomes

- identify the active user, shell, hostname, and package manager
- verify that the work is happening inside Linux rather than the host OS shell
- confirm that core commands needed for the course are present
- record a repeatable environment report before beginning later labs

## Deliverables

- a captured environment report
- a short note explaining where files should live in the VM
- confirmation that the student can reopen the environment later
