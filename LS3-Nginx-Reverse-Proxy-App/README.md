# LS3 Nginx Reverse Proxy App

Run a tiny local application and proxy requests to it with Nginx.

## Outcomes

- distinguish between an application port and a public web server port
- read a minimal reverse-proxy server block
- run a toy app as a background process or service
- verify end-to-end behavior with `curl`, logs, and socket inspection

## Deliverables

- a working toy app on an internal port
- an Nginx reverse-proxy config
- a short comparison between static serving and proxying
